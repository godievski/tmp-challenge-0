# Catálogo de libros

El catálogo muestra obras bibliográficas y el número de ediciones conocidas para cada una.

## Lenguaje

**Libro**:
Obra bibliográfica mostrada como una entrada del catálogo. Puede agrupar varias ediciones.
_Avoid_: Edición, ejemplar

**Edición**:
Publicación concreta de un libro, con datos propios como editorial y fecha.
_Avoid_: Libro, ejemplar
